# Welcome to Subscrio

Subscrio is an open-source entitlement engine for .NET and TypeScript. It stores products, features, plans, customer subscriptions, and overrides in your database, then resolves the feature access or value your application needs.

Start with the [getting-started guide](getting-started.md), review the [core entitlement model](core-overview.md), or go directly to [configuration sync](config-sync.md) and the [feature checker](feature-checker.md).

Subscrio is not a payment processor, feature-flag service, authorization system, or license-key activation service. It can consume billing events and work alongside rollout and authorization tools without putting another hosted entitlement service in the access-check path.
